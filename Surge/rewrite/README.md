Google Rewrite
Safari 谷歌搜索重定向（Surge）


功能
解决使用Safari浏览器默认谷歌搜索需要跳转的问题。

How to use
1. 安装环境
需要有网络调试工具 Surge ，且要付费至具有面板功能
最低支持版本 :

AppStore 版 4.9.3 或更新版本
TestFlight 版 4.11.0 (2014) 或更新版本

2. 模块安装链接
稳定版 : [https://raw.githubusercontent.com/Rabbit-Spec/Surge/Master/Module/Spec/GoogleRewrite/Moore/GoogleRewrite.sgmodule](https://github.com/mouseroser/Surge/blob/main/Surge/rewrite/Google.sgmodule)

3. 安装方式
打开 Surge -> 模块 -> 安装新模块 -> 复制粘贴上方的安装链接 -> 完成!

4. 更新模块方式
请按照以下步骤更新

更新模块本身 :
Surge -> 模块 -> 找到本模块 -> 左滑后点击更新

**两次更新之间建议 _ 间隔 5 分钟以上_，否则又几率页面缓存文档尚未更新导致更新失败
